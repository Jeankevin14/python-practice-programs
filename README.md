# Python Practice Programs

Practice programs from my Python training: 46 questions and 5 scenario problems, from basics up to object-oriented programming.

## How to run

Each file is a standalone script (Python 3, no packages needed):

```bash
python basics/q04_factorial.py
```

Most programs read their input from the keyboard. The comment at the top of each file shows an example input and output.

## Folders

| Folder | Topics |

| [`basics/`](basics/) | Input/output, operators, conditions and loops |

| [`patterns/`](patterns/) | Star and number patterns |
